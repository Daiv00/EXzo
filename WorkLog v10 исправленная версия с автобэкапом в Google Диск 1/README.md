# WorkLog v10 — учёт смен с автобэкапом в Google (без Google Cloud)

Веб-приложение на Flask: смены, расчёт часов и заработка, пользователи, автоматический
бэкап данных в Google Диск через Google Apps Script — без Google Cloud, без сервисных
аккаунтов и без OAuth-консоли.

## Что исправлено по сравнению с v9

1. **Не запускалось в PySpace IDE.** Раньше приложение стартовало как обычный скрипт:
   IDE обрывала процесс по таймауту, а предпросмотр отдавал только статические файлы.
   Теперь в IDE есть кнопка «Запустить сервер» (см. ниже), а приложение корректно
   работает за обратным прокси: `ProxyFix(..., x_prefix=1)`, cookie-путь берётся из
   `X-Forwarded-Prefix`, `COOKIE_SECURE=auto`, `ALLOW_EMBED=1` разрешает встраивание в iframe.
2. **Автобэкап никогда не работал.** В v9 отсутствовала функция `_user_payload()` —
   код бэкапа падал молча. Функция реализована, в выгрузку входят смены и итоги.
3. **Убран весь стек Google Cloud.** Ошибочный вызов `service.about().get(...).execute()`
   и таблицы `google_tokens`, `drive_backups`, `drive_config`, `app_settings` удалены.
   Вместо них одна таблица `backup_config`.
4. **Бэкап = один POST в Apps Script.** Никаких зависимостей Google: `urllib` отправляет
   JSON на адрес веб-приложения Apps Script, секрет хранится зашифрованным (Fernet,
   ключ из `SECRET_KEY`), адрес проверяется — только `https://` и хост, оканчивающийся
   на `google.com`.
5. **Бэкап автоматический.** После завершения смены копия уходит в фоне (демон-поток),
   поэтому интерфейс не подвисает. Есть кнопки «Проверить связь» и «Сохранить сейчас».

## Настройка автобэкапа (5 минут, один раз)

1. Откройте [script.google.com](https://script.google.com) → «Новый проект».
2. Удалите содержимое `Code.gs` и вставьте файл `apps_script/Code.gs` из этого проекта.
3. В строке `const SECRET = '...'` замените значение на свой длинный случайный пароль.
   Запомните его — он понадобится на следующем шаге.
4. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение»:
   - «Запуск от имени»: **я** (ваш аккаунт);
   - «У кого есть доступ»: **у всех** (иначе сервер не сможет отправить данные).
5. Скопируйте **URL веб-приложения** из окна «Развёртывание обновлено» — он выглядит как
   `https://script.google.com/macros/s/…/exec`. Адрес `/dev` не подойдёт: он работает
   только в вашем браузере, сервер по нему получит страницу входа Google.
6. В WorkLog: «Настройки» → карточка «Автобэкап в Google Диск» → вставьте URL и тот же
   секрет и нажмите **«Проверить связь и подключить»**. Кнопка сама сохраняет поля, если
   Диск ответил, — отдельно нажимать «Сохранить» не нужно.
7. Должно появиться «Связь есть», а в Google Диске — папка `WorkLog — Смены` с JSON-файлами.
   Ту же инструкцию из шести шагов можно раскрыть прямо в интерфейсе, в карточке настроек.

После правок кода в Apps Script делайте «Развернуть» → «Управление развёртываниями» →
«Изменить» → версия «Новая», иначе Google продолжит отдавать старую версию скрипта.

Дальше всё само: после каждой завершённой смены данные уезжают в Диск. Статус последнего
бэкапа виден в «Настройках» и в `/api/backup/status`.

## Запуск в PySpace IDE

1. Импортируйте архив проекта: «Импорт ZIP в проект».
2. Откройте `app.py` и нажмите кнопку **«Запустить сервер»** на верхней панели
   (или `Ctrl+K` → «Запустить активный файл как веб-сервер»).
3. Приложение откроется в панели живого предпросмотра. Остановка — та же кнопка
   (`Ctrl+K` → «Остановить веб-сервер проекта»).

Обычный «Запустить» (`Ctrl+Enter`) для веб-серверов не подходит: у него есть таймаут.

## Локальный запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python app.py           # http://127.0.0.1:5000
```

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `SECRET_KEY` | генерируется | подпись сессий и шифрование секрета бэкапа. **Задайте свой**, иначе после перезапуска связь с Apps Script придётся настраивать заново |
| `PORT` | `5000` | порт |
| `HOST` | `0.0.0.0` | адрес прослушивания |
| `COOKIE_SECURE` | `auto` | `1` — только HTTPS, `0` — всегда, `auto` — по схеме запроса |
| `ALLOW_EMBED` | `0` | `1` разрешает открывать приложение в iframe (нужно для предпросмотра в IDE) |
| `WORKLOG_DATA_DIR` | папка проекта | где лежит файл SQLite |
| `BACKUP_TIMEOUT` | `20` | таймаут запроса к Apps Script, секунды |

## Деплой на Render

- Тип сервиса: Web Service, окружение Python.
- Build: `pip install -r requirements.txt`; Start: `python app.py` (или `Procfile`).
- Обязательно задайте `SECRET_KEY` и `COOKIE_SECURE=1`.
- На бесплатном плане диска нет: SQLite исчезает при редеплое и при засыпании сервиса —
  именно поэтому автобэкап в Google Диск важен. Бесплатные сервисы усыпляются после
  15 минут простоя и просыпаются 30–60 секунд ([Render Docs](https://render.com/docs/free)).
- Если нужен постоянный диск — подключите Persistent Disk и укажите
  `WORKLOG_DATA_DIR=/data`.

## Тесты

```bash
python tests/test_worklog.py
```

Проверяются регистрация и вход, старт/финиш смены, итоги, шифрование секрета,
валидация URL, фоновый бэкап после завершения смены, статус и отключение.
В конце должно быть: «Все проверки WorkLog пройдены ✓».
